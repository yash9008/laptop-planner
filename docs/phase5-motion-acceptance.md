## Authority Classifications

Every interaction below is categorized under one of the mandatory authority classifications:
1. **observed/recorded**: Verified via Chrome/Electron DevTools Animations panel or direct interaction recording with measured duration span.
2. **computed**: Read directly from `getComputedStyle` on an active rendered element in the running reference.
3. **loaded declaration only**: Present in a loaded reference stylesheet (`index.D-Ydq_78.css` or inline) but not exercised on live user/task components.
4. **intentional Laptop Planner behavior**: Conscious design or architectural decision where Laptop Planner differs or establishes local offline guarantees (e.g., draft retention, zero-delay modal appearance, atomic SQLite saves, offline safety).
5. **mismatch**: Identified behavioral divergence between reference and local implementation.
6. **unverified**: Interaction or transition where reference evidence is unavailable or unrecorded (private data exclusion, lack of live demo/recorder trace).

## Unverified Reference Behaviors and Remaining Gaps

1. **Current Task Editor Presentation & Nested Menus**:
   - Reference computed styles confirm 0 s transition duration and no CSS animations on editor containers, estimate panel, and quick-add overlays.
   - However, the existence of proprietary JavaScript-driven springs or Web Animations on initial entrance/exit in Sunsama remains **unverified** due to lack of an authorized live recorder trace on an active user task.
   - Laptop Planner intentionally retains immediate, responsive zero-duration overlay appearances, ensuring zero input-to-interaction latency and zero draft risk.

2. **Loaded but Unexercised Reference CSS Declarations**:
   - The 300 ms `margin-right` rule on `.group-right-container`, 300 ms ease-in `.focus-calendar-panel-container` opacity rule, 300 ms/100 ms task fade entry/exit hooks, staged row timing hooks (50 ms / 200 ms), and 500 ms delayed modal fade-in are confirmed present in Sunsama's loaded stylesheets (`index.D-Ydq_78.css`).
   - Per prompt rule 2, these loaded declarations are NOT turned into unobserved trigger behaviors or blanket applied to unrelated surfaces. The 300 ms ease-in calendar opacity transition is specifically applied to `.workspace.focus-view .calendar-dock` where it matches the reference selector intent, while the other hooks remain documented declarations rather than manufactured triggers.

3. **Drag & Drop Physics and Inertia**:
   - Whole-card drag lift, live insertion placeholder, FLIP neighbor reflow (170 ms `cubic-bezier(.2,.8,.2,1)`), and settling ghost animation (180 ms `cubic-bezier(.2,.8,.2,1)`) provide fluid, frame-bounded interactions.
   - The exact easing curves and velocity profiles used by Sunsama's drag engine remain **unverified** because private account data was not inspected and no live synthetic drag recording with frame-level coordinates is available.
   - Laptop Planner preserves its robust, verified Web Animations API implementation with immediate reduced-motion suppression (0 ms duration).

4. **Reference Account Access Limitations**:
   - In accordance with AGENTS.md rule 4 and prompt rule 2, no private user accounts, personal tasks, or cloud integrations were accessed.
   - Synthetic reference observations from October 26, 2026 (`sunsama-phase2-reference.json`, `sunsama-motion-rules.json`, `sunsama-motion-computed.json`) represent the authoritative limits of reference evidence.
